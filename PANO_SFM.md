# Рабочая сборка COLMAP для pano-sfm-proto

## Выводы

**По задаче.** Ветка codex/pano-sfm-aam сохраняет AAM из полного свежего
прогона и нативные расширения базы на официальном COLMAP 4.2.1.

**Для проекта.** Собственный целевой файл pano_aam_mapper собирается из
исходников вместе с обычным colmap. Он копирует исходную БД SQLite в память
перед запуском mapper. Условия отдельного опыта хранятся в его отчёте.

**Следующий шаг.** Для новых опытов фиксировать коммит форка в условиях
запуска. Это позволит воспроизвести использованный вариант движка.

## Сборка и запуск

Используйте [официальные зависимости COLMAP](doc/install.rst). Пример
сборки CPU-варианта траектории с Ninja.

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release \
  -DCUDA_ENABLED=OFF -DGUI_ENABLED=OFF -DONNX_ENABLED=OFF -DMVS_ENABLED=OFF
cmake --build build --target colmap_main pano_aam_mapper
build/src/colmap/exe/pano_aam_mapper --help
```

Обычный colmap mapper в этой ветке использует сортировку AAM. Для копии
БД в памяти передайте pano_aam_mapper параметр --database_path явно.
Список аргументов mapper доступен через --help.

Для обычного AAM запускайте процесс без переменных COLMAP_DIAGNOSTIC_*.
Параметры диагностики могут менять поведение. TRACE включает трассировку и
её ограничения, включая исторический предел 665 кадров по умолчанию.
FIRST_GLOBAL, TRIALS, BA_PREV_FRAMES и BA_PREV_POINTS восстанавливают
состояния расписания и попыток. CHECKS задаёт проверку остановки.
COLMAP_PHYSICAL_RIG_CONFIG включает отдельную модель физического рига.

## Ветки

- codex/pano-sfm-aam — рабочая сборка AAM.
- codex/same-sensor-init — эксперимент с автоматическим стартом
  внутри одного сенсора коцентрического рига.
- codex/mono-terminal-admission4 — экспериментальный фильтр новых
  наблюдений в двух заключительных блоках при 665 кадрах.
- codex/colmap-experiment-archive — исходные патчи и снимки исторических
  сборок для восстановления результатов.

В этой ветке автоматическая инициализация коцентрического рига использует
два разных момента одного сенсора. Все виртуальные виды участвуют
в дальнейшей регистрации. Сопутствующая трассировка первых оптимизаций
включается через COLMAP_DIAGNOSTIC_TRACE.
