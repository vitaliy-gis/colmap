# Источники экспериментальных сборок pano-sfm-proto

## Выводы

**По задаче.** Архив сохраняет локальные патчи и снимки исходников
экспериментальных сборок, обнаруженные на mario.

**Для проекта.** Каталоги checkouts содержат базовый коммит и diff
каждой рабочей копии. Каталоги runs содержат исходники частных сборок
и патчи к их контрольным состояниям.

**Следующий шаг.** Для дальнейшей разработки использовать ветку
codex/pano-sfm-aam. Архив помогает восстановить исторические варианты
при сверке с условиями их запуска.

Исходники рабочих вариантов доступны в codex/pano-sfm-aam,
codex/same-sensor-init и codex/mono-terminal-admission4.
В этой ветке архив размещён отдельно от исходников официального COLMAP.
